# 平台规则与雷区

> 用途：生成选题 / 脚本前先检索本文件，主动避开会让账号限流、下架、甚至封号的坑。二次元赛道雷区比一般赛道多，尤其版权与未成年人两块。

## 一、版权与 IP（二次元头号雷区）

二次元内容最大的合规风险是「未经授权的 IP 使用」。cos 本身通常属于粉丝二创、一般平台默许，但以下情况高危：

- **商用未授权角色**：接商单时如果 cos 的是受严格保护的大 IP（如迪士尼、部分手游），需确认品牌方已拿到授权，否则账号和商单都危险。
- **背景音乐 / BGM**：直接用番剧原声、流行歌做 BGM 极易被系统识别下架音频甚至整条视频。优先用平台自带音乐库、无版权音乐（如 Pixabay、YouTube 音频库），或购买商用授权。
- **素材盗用**：直接扒别人的正片、立绘当自己封面，既违规又得罪圈内人，评论区会反噬。
- **同人尺度**：成人向同人（R18）内容在主流平台一律禁止，发擦边会被限流甚至封号，商单也绝碰。

选题时若涉及强 IP，脚本里应提示「本内容为非商用粉丝二创」，并尽量使用合规音乐，从源头降风险。

## 二、各平台审核红线（通用）

- **抖音 / 小红书**：严格防「低俗擦边、畸形审美、危险行为」。cos 女角色时服装过露、动作暗示都会被限流；特效妆（伤痕、异形）可能误判血腥，需加「特效」标注。导流到站外（微信 / 淘宝）的口播和二维码会被压，需用「主页简介」合规留资。
- **B站**：对「引战、人身攻击、剧透未播内容」敏感；封面党（标题党）容易被举报。分区选错（如把教程塞进动画区）会影响推荐。
- **微博**：热搜 / 话题引流要自然，买量刷转评易被反作弊识别掉权重；带外链短链可能被拦。

一条铁律：**任何平台的「灰色地带」都别碰**，限流一次要养很久才回来，得不偿失。

## 三、未成年人相关规则

coser 赛道常涉及「扮演未成年角色」或「受众含未成年人」，需特别注意：

- 妆容与服装不得刻意幼态化擦边，平台对「儿童软色情」零容忍，误判即封。
- 不得诱导未成年人打赏、私下联系、加群；互动话术避免「私聊姐姐 / 哥哥」这类带引导性的表达。
- 抽奖 / 福利活动要走平台合规组件，不能「评论抽奖加微信」，否则违规且易被薅。

脚本生成时，凡涉及角色年龄偏小的 IP，自动规避「幼态妆 + 暴露服装 + 私下引导」的组合。

## 四、常见限流 / 降权原因（自查清单）

1. 搬运痕迹重（非原创、去重不足）→ 判抄袭降权。
2. 标题党 / 封面与内容不符 → 举报率高，掉推荐。
3. 频繁删改重发同一条 → 触发重复内容机制。
4. 评论区引战、自己小号控评 → 被反作弊识别。
5. 突然大量发外链 / 二维码 → 判营销号限流。
6. 完播率长期过低（尤其抖音前 1 秒没钩子）→ 自然不推。
