# 往期爆款复盘

> 用途：让 AI 选题助手「踩在旧选题肩膀上」，从已验证的爆款里提炼可复用打法，避免重复踩坑、也避免重复老选题。以下为示例复盘模板，正式使用时请替换为账号真实数据（播放 / 涨粉 / 收藏 / 评论）。

## 案例一：高还原 cos 正片（技术流破圈）

- **选题**：某热门游戏新角色上线当周，抢做「高还原正片 + 角色设定对比图」。
- **为什么爆**：踩中 IP 热度窗口（新角色讨论峰值），对比图满足「考据党」的认同需求，评论区大量「神还原」正向反馈推高互动。
- **数据表现**：单条播放为账号均值 8 倍，涨粉集中在该条发布后 3 天，收藏率低但转发高（适合破圈）。
- **可复用打法**：① 紧盯新番 / 新游「角色上线周」做抢发；② 正片必带「原设 vs 还原」对比，给考据党谈资；③ 评论区主动抛「下一个 cos 谁」承接流量。

## 案例二：新手向教程（长尾收藏王）

- **选题**：《平价假发怎么打理出不廉价的感觉》——针对想入坑但预算低的小白。
- **为什么爆**：击中「新手误区 + 平替」两个高收藏关键词，标题带「平价 / 不廉价」形成反差；全程无门槛，看完能照做。
- **数据表现**：播放中等但**收藏率是均值 5 倍**，长尾搜索流量持续 2 个月，带来稳定涨粉而非爆发。
- **可复用打法**：① 教程选题永远绑定「误区 / 平替 / 避雷」三个高收藏词之一；② 步骤拆到「跟着做就能成」，别炫术语；③ 结尾埋「下一期教 XX」做连载预期，拉回看。

## 案例三：展场 Vlog 联动（互动 + 破圈）

- **选题**：漫展 day1 开箱 + 和三位画手 / 手工娘联动出镜，标题用投票「下次展想去哪」。
- **为什么爆**：联动互相导流，三方粉丝叠加；投票拉评论，评论量触发算法推流；「开箱 + 真人感」强化陪伴属性。
- **数据表现**：评论量为均值 6 倍，是互动指标最强的一条；涨粉来自联动方粉丝回流。
- **可复用打法**：① 联动优先选「互补赛道」（画手 / 手工 / 妆娘），而非同类 coser 互抢；② 必须设计「互动钩子」（投票 / 提问）把流量变成评论；③ 展前预热 + 展后复盘做成系列，吃漫展周期流量。

## 可复用打法总表（给选题助手直接调用）

| 打法 | 适用场景 | 必须包含的要素 |
|---|---|---|
| 抢热点还原 | 新番 / 新游角色上线周 | 原设对比图 + 上线时间窗 + 评论区承接 |
| 新手教程 | 长效涨粉 / 搜索流量 | 误区 / 平替 / 避雷关键词 + 零门槛步骤 + 连载钩子 |
| 联动 Vlog | 破圈 / 冲互动指标 | 互补赛道搭档 + 互动投票 + 展期系列化 |
| 日常陪伴 | 掉粉期 / 维持粘性 | 真人感 + 共鸣话题，不求爆量求互动 |

> 生成新选题时，优先从上述打法中匹配一种，并确认要素齐全；重复老选题需换角度或换 IP，避免与往期同质。
