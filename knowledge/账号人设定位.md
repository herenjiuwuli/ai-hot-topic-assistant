# 账号人设定位

> 用途：给 AI 选题助手提供「coser 账号人设」的定位方法论，生成选题 / 脚本前先检索本文件，确保内容风格、语气、选题口径与账号人设一致，避免人设飘移让老粉出戏。
> 适用账号：MCN 旗下 coser 达人（动画 / 漫画 / 游戏 / VTuber / 手办 / 同人方向）。

## 一、为什么先定人设再定内容

很多新号一上来就追热点、抄爆款，结果粉丝来了又走——因为账号没有「人格」，用户记不住你。人设是账号的地基：它决定了你 cos 谁、说什么话、用什么语气、接什么商单。没有清晰人设，内容越爆越容易「飘」，今天萌新感明天高冷御姐，老粉会困惑、取关。所以运营第一步永远是「想清楚你是谁」，再谈选题和脚本。一个好的人设要同时满足三点：有辨识度（别人一眼记住）、可持续（你能稳定产出）、能变现（商家愿意投）。

## 二、人设三问（定位的起点）

定人设先回答三个问题。① 你是谁：cos 哪类 IP（国产番 / 日番 / 游戏 / 原创）？擅长神还原还是创意整活？② 给谁看：核心粉丝是考据党、颜控、还是入坑萌新？他们的痛点是什么（找不到教程 / 看不懂出处 / 想要平替）？③ 在哪变现：商单（品牌植入）、带货（谷美 / 假发）、还是知识付费（教程）？三问答案交叉后，账号的「人设坐标」就出来了。例子：「专注国产乙女游戏、陪你聊剧情梗的邻家感 coser，接游戏联名商单」——一句话能说清，就是好定位。

## 三、两种主流人设及适用场景

coser 账号最常见两种人设路线。路线 A「神还原技术流」：突出专业度，正片精度高、考据严谨，吸引审美党和同好，商单溢价高，但起号慢、对妆造道具门槛高。路线 B「邻家陪伴感」：突出真人性格，聊天、开箱、吐槽、追番，互动强、涨粉快、容错高，适合新人冷启动，但专业背书弱、同质化竞争大。建议新人先用 B 起量、积累基础粉丝后叠加 A 的专业内容做信任升级，而非一上来硬凹技术人设导致更新压力爆表。

## 四、人设一致性清单（对外四件套）

人设要落地到每个触点，老粉才不会被「另一个你」劝退。检查清单：① 头像 / 封面：固定用高还原正片或统一视觉，别今天猫娘明天剑修；② 简介：一句话讲清「你是谁 + 给粉丝什么」，带固定 tag；③ 口头禅 / 开场：视频开头和评论区回复保持同一语气（毒舌 / 温柔 / 沙雕）；④ 视觉色调：剪辑滤镜、字幕字体、封面排版统一。这四件套稳定两三个月，算法和粉丝才会给你打上明确标签，推流更精准。

## 五、从 0 到 1 的人设验证方法

人设不是拍脑袋定的，要用小样本测出来。方法：先发 3–5 条不同人设侧重的视频（一条纯还原、一条聊天向、一条教程向），观察哪类评论最热、完播最高、涨粉最猛。评论区高频词就是你的「人设锚点」——比如粉丝总说「姐姐好温柔」，说明邻家感是你的资产，就往这靠。切记：让数据反推人设，而不是用理想人设硬套数据。验证期控制在 2–3 周，定型后再固定栏目比例。

## 六、人设翻车雷区（务必避开）

人设最怕「飘」和「假」。雷区一：人设飘移，今天御姐明天萌新，老粉认知混乱。雷区二：抄袭人设，照搬别的爆款账号的语气人设，粉丝一眼识破且易引战。雷区三：过度包装，立「大神」人设但基础翻车，被反向补课。雷区四：人设与商单冲突，比如邻家感人接了高冷奢侈品，粉丝觉得违和取关。守住原则：人设可以成长，但不能背叛粉丝对你的「初始印象」。
